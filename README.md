列表接口接受前端传来的排序字段后，攻击者把未授权的薪资字段塞进排序参数，靠翻页顺序推断出了每个员工的薪资：多个排序键按给出顺序比较，前一个相同时才比较后一个，数字按数值比较，空值按策略排在最前或最后，字符串按码点比较，降序只作用于对应的键；排序须稳定，相同键的记录保持原有相对顺序，不得修改入参列表，批量排序的各批相互独立。不变量：排序两次结果相同，排序不改变记录数量与内容。

## 排序规格

排序规格是一个列表。每个元素描述一个排序键，包含 field、direction 与 nulls 三个属性。direction 取 asc 或 desc。nulls 取 first 或 last。多个键按列表顺序生效。

字段值可以是数字、字符串或空值。空值使用 None 表示。记录使用字典表示。
